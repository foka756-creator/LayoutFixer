# LayoutFixer

Приложение для строки меню macOS 15: исправляет слово, набранное не в той раскладке (EN ⇄ RU).

- Срабатывает по пробелу: слово не найдено в словаре своего языка, но найдено после смены раскладки.
- Backspace сразу после замены откатывает её; слово попадает в список исключений (меню «Исключения»).
- Нужны разрешения «Универсальный доступ» и «Мониторинг ввода».

```bash
./test.sh   # тесты ядра
./build.sh  # собирает build/LayoutFixer.app (ad-hoc подпись)
```
